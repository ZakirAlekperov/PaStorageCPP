Detailed Description

Модульные тесты класса PasswordEntry.

Проверяет корректность хранения и изменения данных учётной записи.

Тестирование выполняется с помощью GoogleTest.

Каждый тест проверяет отдельное требование к публичному интерфейсу PasswordEntry.
