\doxysubsection{Detailed Description}
Объявление типов ошибок валидации Pa\+Storage. 

Содержит перечисление кодов ошибок и класс исключения для обработки некорректных данных.

Позволяет различать ошибки по программному коду, независимо от языка диагностического сообщения.
