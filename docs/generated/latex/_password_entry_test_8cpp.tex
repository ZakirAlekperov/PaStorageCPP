\doxysubsection{Detailed Description}
Модульные тесты класса \doxylink{class_password_entry}{Password\+Entry}. 

Проверяет корректность хранения и изменения данных учётной записи.

Тестирование выполняется с помощью Google\+Test.

Каждый тест проверяет отдельное требование к публичному интерфейсу \doxylink{class_password_entry}{Password\+Entry}.
