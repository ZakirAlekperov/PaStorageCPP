\doxysubsection{Detailed Description}
Представляет запись учётной записи. 

Хранит название сервиса и имя пользователя.

Название сервиса задаётся при создании объекта и не может быть изменено через публичный интерфейс.

Имя пользователя можно получить и изменить с помощью соответствующих методов.

Класс не выполняет сохранение данных на диск и не содержит криптографической функциональности.

Изменяет имя пользователя. 

Проверяет новое значение перед сохранением.

Пустое имя пользователя допускается, но строка, состоящая только из ASCII-\/пробельных символов, считается некорректной.

При ошибке валидации прежнее значение сохраняется.
