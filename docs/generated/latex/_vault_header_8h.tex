\doxysubsection{Detailed Description}
Объявление фиксированного заголовка хранилища. 

Определяет начальные 16 байт бинарного файла Pa\+Storage.

Заголовок позволяет распознать формат файла и проверить совместимость его версии.

Класс не реализует шифрование и не работает с диском.
