\doxysubsection{Detailed Description}
Модульные тесты проверки имён пользователей. 

Проверяет правила допустимости username.

Пустые имена пользователей разрешены. Значения, состоящие исключительно из ASCII-\/пробельных символов, должны отклоняться.
